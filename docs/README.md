## For contributors

How the daemon works internally is documented under [`architecture/`](https://github.com/MikalaiBarysevich/CleverSwitch/tree/main/docs/architecture/): topics and subscribers, device lifecycle, info tasks, transports, logging internals and edge-switch backends. Read only the page for the subsystem you are changing.
